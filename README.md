# Bean & Bloom — Coffee Shop Mobile App

A responsive React + Vite coffee shop mobile UI with searchable coffee, category filters, favorites, cart quantity controls, checkout interaction, promotional banner, and nearby cafe card.

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open Terminal in the project folder and run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite (usually `http://localhost:5173`).

## Production build
```bash
npm run build
npm run preview
```

## Notes
- Product photos load from Unsplash, so an internet connection is required for those images.
- This is a frontend demo. Checkout shows a local confirmation and does not process payments.
- The supplied Figma URL could not be opened in this environment, so this is a polished responsive implementation based on the coffee-shop mobile app brief, not a verified pixel-perfect reproduction. For an exact match, provide screenshots/exported frames from Figma.
